# Sohil Khan — Portfolio

Personal portfolio of **Sohil Khan**, Software Engineer | Full-Stack Developer.

- Stack: React, TypeScript, Vite, Tailwind CSS, Framer Motion
- Features: pixel-art football banner, command palette, GitHub heatmap, experiments section
- Design inspired by Harshit Raghuwanshi's portfolio (used with adaptation for personal use)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

All personal data, projects, skills, and links live in `src/config/site.ts`.
